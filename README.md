# luci-app-wol-autowake

远程连接自动唤醒：当外部有人连接某台设备的端口时，如果设备不在线，路由器自动发送 WOL 魔术包把它唤醒。

带 LuCI 图形界面，设备数量不限，按「外部端口」区分设备。

---

## 功能

- 多设备管理：每台设备独立配置名称、MAC、内网 IP、外部端口、目标端口和协议。
- 自动唤醒：防火墙记录到外部连接后，自动判断设备是否在线，离线才发送魔术包。
- 手动唤醒：设备列表里可直接点「唤醒」。
- 在线检测：支持自适应 ping、邻居表 + ping、纯被动邻居表三种方式。
- 白名单：命中后无条件唤醒，优先级最高。
- 黑名单：手动和自动条目统一管理，支持修改 IP 和过期时间。
- 自动黑名单：同一来源每分钟忽略次数或累计忽略次数达到阈值时自动加入。
- 扫描器预设：内置常见国内扫描器网段，避免扫描流量反复触发。
- 来源过滤：可忽略国外 IP、忽略 IPv6 来源。
- 归属地查询：支持在线查询和本地查询，结果缓存复用。
- IPv6 放行：端口转发之外，可额外创建 IPv6 放行规则。
- 内网回环唤醒：在家用公网地址访问设备时也能触发。
- 防火墙联动：黑名单可同步到 fw4 防火墙，直接拦截入站和端口转发。
- 日志：最近唤醒、忽略记录、可疑来源；支持清理、备份和导出。

## 环境要求

- OpenWrt / iStoreOS，使用 fw4（nftables）。
- LuCI。
- 依赖：
  - `etherwake`
  - `ipset`
  - `ip-full`
  - `kmod-nf-nat` 等系统默认网络组件

安装依赖：

```sh
opkg update
opkg install etherwake ipset ip-full
```

## 安装

### 方式一：IPK

```sh
opkg install luci-app-wol-autowake_1.0.0-1_all.ipk
```

安装后刷新 LuCI。

### 方式二：tar.gz 手动安装

```sh
tar -xzf luci-app-wol-autowake-1.0.0.tar.gz
cd luci-app-wol-autowake
sh install.sh
/etc/init.d/wol-autowake enable
/etc/init.d/wol-autowake start
```

### 方式三：脚本安装

```sh
sh install.sh
```

安装完成后重启 LuCI 或刷新页面。

## 使用方法

### 1. 添加设备

进入 LuCI：

```text
服务 → 自动唤醒
```

在「设备」标签页点「添加」：

| 字段 | 说明 |
|---|---|
| 名称 | 设备名称，例如「我的电脑」 |
| MAC 地址 | 设备网卡 MAC，用于发送 WOL 魔术包 |
| 内网 IP | 设备在局域网内的固定 IP，用于在线检测和端口转发 |
| 外部端口 | 外网访问使用的端口 |
| 目标端口 | 设备实际监听的端口，例如 RDP 的 3389 |
| 转发协议 | TCP、UDP 或两者 |
| 创建 IPv6 放行 | IPv6 访问时额外创建放行规则 |

保存后，在设备列表中打开「转发开」。

### 2. 配置端口转发

设备行内会显示：

- 在线状态
- IPv4 端口转发状态
- IPv6 放行状态

「转发开」会自动创建对应的防火墙规则；「转发关」只删除本应用创建的规则。

### 3. 手动唤醒

在设备列表中点「唤醒」，设备会立即收到魔术包。

手动唤醒会记录为：

```text
唤醒 [设备] 手动唤醒 端口=- 来源=
```

来源显示为无，说明为「手动唤醒」。

### 4. 白名单

进入「设置 → 白名单」。

- 白名单中的 IP 无条件唤醒；
- 支持单个 IP 或 CIDR；
- 支持行内编辑、删除、保存。

### 5. 黑名单

进入「设置 → 自定义黑名单」。

- 手动和自动黑名单统一显示；
- 每行可编辑 IP 和过期时间；
- 过期时间填小时数，留空表示永久；
- 保存后显示具体到期日期；
- 删除即移除该条目。

自动黑名单在「高级设置」中启用和调整阈值。

### 6. 自动黑名单

高级设置中可配置：

- 启用自动黑名单；
- 每分钟忽略次数；
- 累计忽略次数；
- 自动解封时间（小时，0 或留空为永久）。

触发后，来源 IP 会自动加入黑名单，并在忽略记录中显示加入原因。

### 7. 来源过滤

设置页可开启：

- 忽略国外 IP：只唤醒中国大陆来源；
- 忽略 IPv6 来源；
- 国内 IP 数据来源：OpenClash 数据或自行下载；
- 内网走公网也能触发唤醒。

### 8. 归属地查询

设置页可选择：

- 在线查询：显示国家 / 省 / 市；
- 本地查询：不联网，只判断国内 / 国外；
- 本地精确查询：下载本地库后离线显示省市。

归属地结果会缓存，已查询过的 IP 不会重复查询。

### 9. 日志

「设备」页可查看：

- 最近唤醒记录；
- 忽略记录；
- 可疑来源 IP。

唤醒和忽略记录按 IP 合并显示，同一 IP 次数累加。

「高级设置」中可：

- 立即清理日志；
- 备份当前日志；
- 导出日志文件。

备份路径：

```text
/root/wol-autowake.log.bak-YYYYMMDD-HHMMSS
```

### 10. 防火墙黑名单

高级设置中开启「黑名单加入防火墙规则」后：

- 黑名单 IPv4 会写入 fw4 原生集合；
- WAN 入站和端口转发都会被丢弃；
- 关闭后只忽略唤醒，不拦截连接。

## 常见问题

### 设备没有自动唤醒

检查：

1. 设备是否真的离线；
2. 外部端口是否正确；
3. 防火墙端口转发是否开启；
4. 来源是否被白名单、黑名单或来源过滤拦截；
5. 设备是否支持 WOL，BIOS / 网卡是否开启网络唤醒。

### 手动唤醒成功但设备没反应

- 确认 MAC 地址正确；
- 确认发送接口是 `br-lan`；
- 确认设备网卡和主板支持 WOL。

### 看不到最近唤醒记录

- 确认日志文件存在：
  ```text
  /root/wol-autowake.log
  ```
- 在「高级设置」检查日志清理设置；
- 刷新页面或重新进入。

### IPv6 访问不能唤醒

- 确认设备配置里开启了「创建 IPv6 放行」；
- 确认系统防火墙允许该端口；
- IPv6 没有 NAT，只需要放行，不需要端口转发。

## 卸载

```sh
opkg remove luci-app-wol-autowake
```

手动安装的包可删除：

```sh
rm -f /etc/config/wol_autowake
rm -f /etc/init.d/wol-autowake
rm -f /usr/bin/wol-*
rm -f /usr/libexec/wol-autowake.sh
rm -f /usr/libexec/wol-fw.sh
rm -f /www/cgi-bin/wol-ctl
rm -f /www/cgi-bin/wol-status
rm -f /www/cgi-bin/wol-log
```
