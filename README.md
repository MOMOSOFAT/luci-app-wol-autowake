# luci-app-wol-autowake

**远程连接自动唤醒** —— 当有人从外部连接某台设备的端口时，如果它不在线，路由器自动发送 WOL 魔术包把它叫起来。

带完整 LuCI 图形界面，设备数量不限，按「外部端口」区分设备。
**端口转发和防火墙规则全部自动生成**，你只需要在网页上填一张表。

---

## 它解决什么

```
你人在外面，想连家里的台式机
        ↓
手机点「远程桌面」→ 连 mypc.example.com:3389
        ↓
台式机在睡眠，连不上
        ↓
路由器看到这次连接尝试
        ↓
自动发魔术包 → 台式机 20 秒后开机
        ↓
再点一次远程桌面 → 连上了
```

不用手动开 WOL 工具，不用记得先叫醒再连。

## 安装

### 系统是 apk（iStoreOS / OpenWrt 24.10+）

```sh
# 在电脑上执行
scp luci-app-wol-autowake-1.0.0.tar.gz root@192.168.1.1:/tmp/

# 登录路由器执行
tar -xzf /tmp/luci-app-wol-autowake-1.0.0.tar.gz -C /tmp
sh /tmp/luci-app-wol-autowake/install.sh
```

### 系统是 opkg（OpenWrt 23.05 及更早）

```sh
opkg install luci-app-wol-autowake_1.0.0-1_all.ipk
```

安装脚本会自动装依赖 `etherwake`、启用服务、清理 LuCI 缓存。

装完打开 **服务 → 自动唤醒**。

## 使用：添加第一台设备

### 第 1 步：打开界面

**服务 → 自动唤醒**，默认停在「设备」页。

页面顶部会显示服务状态，正常时是绿色的 **● 就绪**。

### 第 2 步：点「添加」

设备列表下面的蓝色 **添加** 按钮。

### 第 3 步：填表

| 字段 | 填什么 | 说明 |
|---|---|---|
| **启用** | ✅ 勾上 | 不勾就不参与自动唤醒 |
| **名称** | `我的台式机` | 只用来显示，随便填 |
| **外部端口** | `3389` | **从外面连过来的那个端口**，用来识别是哪台设备 |
| **目标端口** | 留空 | 留空 = 与外部端口相同。只有两者不一样时才需要填 |
| **内网 IP** | `192.168.1.10` | 这台设备在局域网里的地址 |
| **MAC 地址** | `aa:bb:cc:dd:ee:ff` | **必填**，魔术包就是发到这个 MAC |
| **转发协议** | `TCP` | 远程桌面选 TCP 就够 |
| **创建 IPv6 放行** | 看需要 | 勾上会额外生成一条 IPv6 放行规则 |

点 **保存**。

### 就完成了

保存后插件会自动做完这些事：

- ✅ 生成 **IPv4 端口转发**规则（外部端口 → 内网 IP:目标端口）
- ✅ 生成 **防火墙日志规则**（用来捕获连接尝试）
- ✅ 勾了 IPv6 的话，额外生成 **IPv6 放行**规则
- ✅ 重载防火墙，**不用你手动去配任何转发**

设备列表里对应那台机器的 **IPv4 端口转发** / **IPv6 放行** 两列会显示勾选框，
点一下就能临时关掉某一条，不用删设备。

## 设备列表怎么看

| 列 | 含义 |
|---|---|
| **启用** | 这台设备是否参与自动唤醒 |
| **名称** | 你填的名字 |
| **外部端口** | 从外面连的端口 |
| **目标端口** | 转发到内网的目标端口 |
| **在线** | 实时状态（绿色=在线） |
| **IPv4 端口转发** | 勾选 = 这条 DNAT 规则已启用 |
| **IPv6 放行** | 勾选 = 这条 IPv6 放行规则已启用 |
| **操作** | 唤醒 / 编辑 / 删除 |

> 「在线」「IPv4 端口转发」「IPv6 放行」都是实时状态，点勾选框立刻生效。

## 设置说明

**设置** 标签页里的项目，一般装完就不用动了。常用的几个：

| 设置 | 默认 | 什么时候改 |
|---|---|---|
| **每设备节流（秒）** | `60` | 同一设备这段时间内只唤醒一次。嫌唤醒太频繁可以调大 |
| **忽略国外 IP** | 关 | **建议打开**。打开后只有中国大陆来源才唤醒，国外来源只记日志 |
| **忽略 IPv6 来源** | 开 | IPv6 段数据不全，扫描器常拿 IPv6 探测，建议保持开启 |
| **内网走公网也能触发** | 关 | 在家用「公网地址」访问设备时也想触发唤醒，就打开 |
| **使用国内扫描器预设黑名单** | 开 | 内置 18 段常见扫描网段。注意：**如果你自己用云主机远程，可能会被误挡** |
| **白名单** | 空 | 填进去的 IP **无条件唤醒**，优先级最高 |
| **手动黑名单** | 空 | 填进去的 IP **一律不唤醒** |
| **启用定期清理** | 开 | 日志超过阈值自动截断，防止 flash 被写满 |

过滤优先级：**白名单 → 黑名单 → 国内 IP 判断 → 节流 → 在线判断 → 唤醒**

## 常见问题

**Q：设备列表里显示「在线」，但远程还是连不上？**

A：插件只管**唤醒**，不管转发是否通。先确认端口转发规则在
**网络 → 防火墙 → 端口转发** 里存在且已启用。

---

**Q：电脑不睡但也没开机，能唤醒吗？**

A：不能。WOL 只能把**支持 WOL 的网卡从睡眠/关机状态**叫起来。
BIOS 里要开启 `Wake on LAN` / `Power On By PCI-E`，Windows 网卡属性里要勾
「允许此设备唤醒计算机」。

---

**Q：连不上时完全没有唤醒记录？**

A：按顺序查：

1. **设置 → 监听防火墙日志** 是否勾上（关掉整个自动唤醒就失效了）
2. **忽略国外 IP** 打开时，你的来源 IP 是否在中国大陆
3. **手动黑名单** 里有没有这条 IP
4. 设备页下拉到 **可疑来源 IP**，看看这次连接有没有被记录、被判定成什么

---

**Q：怎么确认 MAC 地址填对了？**

A：在设备页点 **唤醒** 按钮手动发一次。如果电脑能醒，说明 MAC 对了；
如果醒不了，先查 MAC，再查 BIOS / 网卡设置。

## 安全建议：换掉默认端口

文档示例统一用 **3389**（远程桌面标准端口），因为最常见、最好理解。

但 **3389 是全网扫描最密集的端口之一**。直接暴露到公网会收到大量爆破尝试，
即使有「忽略国外 IP + 扫描器黑名单」挡着，日志也会被刷爆。

**建议换成高位端口**（如 `21389`、`32412`），在填表时这样写：

```
外部端口  21389
目标端口  3389
```

于是：

```
手机连  mypc.example.com:21389
  → 路由器把 21389 转到 192.168.1.10:3389
```

既能正常用远程桌面，又能把绝大部分扫描挡在门外。
